# Change Log

All notable changes to the "sprintflint" extension will be documented in this file.

## [0.1.0] - 2026-02-12

### Added
- Initial release
- My Issues, Current Sprint, and Backlog sidebar views
- Issue tree view with status icons (backlog, todo, in_progress, review, done)
- Create issues from VS Code
- Search issues across all sprints
- View issue details in webview panel
- Trigger autoplay (AI agents) directly from sidebar
- Authenticate with API token
